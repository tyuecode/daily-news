# 每日热点简报站（v2 · 重写版）

每天自动更新的中文热点简报：**打开首页 30 秒内，知道今天国内外发生了哪些大事**。
托管在 Cloudflare Pages + 自有域名，中国大陆无需翻墙即可访问。

> 本站**不是**翻译站，也不是舆情监控工具。它只做三件事：
> 1. 用真实热搜榜告诉你「国内此刻最热的事」；
> 2. 用多家英文媒体的中文译文告诉你「国际此刻最热的事」；
> 3. 想深挖时，点开卡片看多家媒体的并列报道（默认折叠）。

---

## 一、设计原则（优先级从高到低）

```
易用性  >  观点多样性  >  工程完美性
热点准确性 > 信息完整性 > 覆盖广度
```

- 国内热点来自 **newsnow 统一热榜 API**（9 个平台，自带排名），不按发布时间排序。
- 国际热点来自 **7 个英文 RSS**，标题翻译成中文，同一事件的多家报道并列展示。
- **不做 AI 总结**：直接展示标题，从根上消除「AI 编造」问题。
- 多家报道默认折叠，首页每张卡片只有一行标题，不让观点对比干扰「看热点」。

## 三、热点算法

每条热搜的分数 = `0.6 × rank + 0.3 × frequency + 0.1 × hotness`（均归一化到 0–1）：

| 维度 | 含义 | 计算 |
|---|---|---|
| `rank` | 榜单排名 | 第 1 名 = 1.0，第 N 名 = 1 − (N−1)/榜单长度；多平台取最好名次 |
| `frequency` | 持续性 | 该话题在最近 7 天快照中出现的次数（每天 3 次抓取） |
| `hotness` | 跨平台广度 | 同一话题出现在几个平台（中文 bigram Jaccard ≥ 0.35 判定） |

- 卡片显示：排名徽章、来源平台、🆕 新增 / 持续 N 次、N 家媒体报道。
- 链接安全：只接受 `https://` 且域名与平台预期匹配的链接，防链接劫持。

### 国内热点质量筛选（大事件优先，不凑数）

国内版块**只要 8 条精品卡**，不追求数量：

1. **剔除低信息量标题**：纯缩写（APEC / G20）、过短标题（<4 汉字）、
   花絮八卦（「握手摘手套」「拍拍拍」「知识点」等）。
2. **大事件加权**：含「习近平 / 会见 / 峰会 / 国务院 / 发布 / 政策 / 首次」等
   信号词的标题，每条 +0.02（最多 +0.12），重新排序后置顶。
3. **兜底**：若过滤后不足 8 条，退回未过滤列表补足，保证闸门不会误伤。

国际版块维持 15 条，多源卡继续置顶（按方案 B，不设媒体配额）。

## 四、运行机制

GitHub Actions 每天北京时间 **8:00 / 14:00 / 20:00**（UTC `0 0,6,12 * * *`）运行：

1. **守卫**：仓库名必须是 `tyuecode/daily-news`，否则立即退出（绝不碰主页仓库）。
2. **冒烟测试**：`python smoke_test.py`，失败即中止。
3. **采集**：并发抓 9 个热榜平台 + 7 个英文 RSS（单源失败跳过，不阻断）。
4. **快照与算分**：保存快照，读最近 7 天算 frequency，跨平台合并算 hotness。
5. **翻译**：英文标题每批 8 条翻译，失败回退英文原文。
6. **播报与语音**：改写 600 字内播报稿（强制完整结尾），edge-tts 生成音频。
7. **发布闸门**：国内/国际各 ≥3 条、链接合法、中文占比 >60%、音频头合法；
   不通过则**不写任何文件**，保留上一版页面。
8. **输出**：写 `entries.json` → 渲染首页与归档 → 清理 30 天前数据 → 提交 → 部署 CF Pages。

## 六、我自己要做哪几步（部署清单）

1. **确认仓库** `tyuecode/daily-news`（已复用原项目仓库，remote 正确）。
   - 该仓库已清空旧代码并以 v2 重建；workflow 守卫已同步改为 `tyuecode/daily-news`。
   - 绝对不要推到 `tyuecode/tyuecode.github.io`。
2. **添加 3 个 Secrets**（仓库 Settings → Secrets and variables → Actions）：
   - `CF_ACCOUNT_ID`：Cloudflare 账户 ID。
   - `CF_API_TOKEN`：需同时勾选 **Workers AI:Edit** 和 **Pages:Edit** 两个权限
     （缺 Pages:Edit 会导致生成成功但部署失败）。
   - `CF_PAGES_PROJECT`：Cloudflare Pages 项目名。
3. **Cloudflare 后台创建 Pages 项目**，绑定自定义域名（加 CNAME 记录）。
4. **Actions 页手动触发一次** Run workflow，打开域名确认页面正常。
5. **以后每天北京 8:00 / 14:00 / 20:00 自动更新**；GitHub 定时高峰延迟 5–45 分钟属正常。

## 七、常见问题

- **页面显示「暂无数据」**：说明当天发布闸门没过（条数不足或抓取全失败），
  系统保留了上一版页面；看 `data/runs/` 下的运行报告定位原因。
- **音频没播**：TTS 失败时会降级为「朗读播报」按钮，用浏览器朗读；
  归档页按设计不放播放器。
- **国内版块混入国际新闻**：国内热点只来自热榜 API，本身按平台区分；
  若将来加中文国际源，涉华判定只看标题不看摘要。
- **移动端**：卡片、字体、触摸区均按手机优先设计（≥44px），响应式布局。

### 页面观感设计

- **今日焦点横条**：顶部用醒目色块显示国内前两条 + 国际第一条标题，打开即抓住重点。
- **概览数字条**：显示「N 条国内 · N 条国际 · 来自 N 个热榜平台」，给出信息量确定感。
- **大事件视觉分级**：国内前 3 条、国际前 2 条用头条样式（大字号、红色左边框、渐变背景），其余为普通卡。
- **热点徽章**：🆕 新增 / 持续 N 次 / N 家媒体报道，分别用不同底色徽章呈现。
- **英文标题弱化**：国际卡的英文原标题为小字灰字，hover 才加深，强化中文优先。
- **版块跳转 + 回到顶部**：顶部锚点按钮一键跳到国内/国际版块，右下角悬浮回到顶部。
- **往期时间线**：首页「往期回顾」用时间线样式，每条显示当天头条摘要。
- **展开区图片**：多家媒体报道的图片只在折叠区显示（`loading=lazy` + `onerror` 隐藏），不进默认视图。
- **暗色模式**：跟随系统 `prefers-color-scheme` 自动切换。

### 语音播报

- **TTS 生成**：edge-tts 7.x，播报稿先做文本归一化（段落空行转自然停顿、折叠重复标点），
  语速 `-5%` 提升新闻清晰度；主音色 `zh-CN-XiaoxiaoNeural` 连续失败过半后自动切换
  备用音色 `zh-CN-YunxiNeural`，8 次线性退避。
- **统一播放控制条**：大号播放/暂停按钮（52px，触摸友好）+ 停止按钮 + 0.85x/1x/1.25x/1.5x
  语速切换 + 实时状态提示。
- **朗读降级可控**：TTS 失败时用浏览器 SpeechSynthesis 朗读，自动挑选中文语音
  （监听 `voiceschanged`），同样支持暂停/继续/停止/语速切换，不再是「点一下无法控制」。

## 八、实测记录（2026-11-18）

- newsnow 9 个平台全部可用；注意缓存命中时 `status="cache"`，必须和 `"success"` 一样接受，
  否则只会拿到 2/9 个平台（已在代码与冒烟测试中固化）。
- 国内直连即可访问 newsnow API；英文 RSS 在境外网络（GitHub Actions）抓取，
  本机国内直连部分源会被拦，属正常现象，不影响线上。
- feedparser 的 `published_parsed` 是 UTC 时间，新鲜度比较统一转朴素日期，避免时区混用崩溃。
